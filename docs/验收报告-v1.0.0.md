## 三、本轮改动清单

### 3.1 图标（本次首要问题）

| 位置 | 处理 | 复验 |
|---|---|---|
| 桌面快捷方式 `fconv 文件格式转换.lnk` | 删除重建，图标指向 `assets/icon.ico,0` | shell 解析 + 截图确认 |
| 工具箱内备份快捷方式 | 同上 | 同上 |
| 开始菜单项 | 本次新增 | 同上 |
| 图标资源本身 | `scripts/make-icons.py` 改为逐尺寸从 1024 主图降采样 | 16/24/32/48/64/128/256 七档逐帧检查 |
| 系统图标/缩略图缓存 | 停 explorer → 清 `IconCache.db` + `iconcache_*.db` + `thumbcache_*.db`（30 个文件）→ 重启 explorer | 复验后重新渲染无旧图 |

原因说明：图标文件换了但显示没换，通常是 Windows 的图标缓存按「路径+序号」缓存了旧图；
仅重建快捷方式不够，必须清缓存。本轮把「重建快捷方式 + 清缓存 + 复验」做成一套可重跑的动作。

## 六、已知限制

- 仅验证 Windows 10/11；macOS / Linux 未适配（启动脚本按 Windows 写）。
- 音视频转换依赖外部 FFmpeg（本项目不分发其二进制）；PDF → 图片依赖 AGPL 的 PyMuPDF（默认不装）。
- DOCX / XLSX / PPTX 仅能识别、不支持转换。
- GIF 导出固定 10fps、宽 480，未参数化。
- 扫描件 PDF 无内嵌文字时，PDF → TXT 结果为空（仅提示，未内置 OCR）。
- 转换历史默认保留最近 2000 条。
- 「工具箱」目录是使用者本机的个人目录，开源版安装脚本不写它（本机由人工归置）。
