## 一、项目概览

**fconv** 是一个面向大学生和职场新人的实用文件格式转换工具。

- **核心理念**：拖进去 → 选格式 → 出来，零门槛体验
- **目标用户**：需要批量转换作业文件、证件照、简历的学生和职场新人
- **技术定位**：工程 + 分发 + 体验项目，不做转换算法

## 二、支持格式矩阵

### 图片格式（全支持，无需外部依赖）

| 源格式 | 目标格式 |
|--------|----------|
| PNG | JPG, WEBP, GIF, BMP, TIFF, ICO |
| JPG | PNG, WEBP, GIF, BMP, TIFF |
| WEBP | PNG, JPG, GIF, BMP, TIFF |
| GIF | PNG, JPG, WEBP, BMP, ICO |
| BMP | PNG, JPG, WEBP, GIF, TIFF |
| TIFF | PNG, JPG, WEBP, GIF, BMP |

### 视频格式（需 FFmpeg）

| 源格式 | 目标格式 |
|--------|----------|
| MP4 | MKV, AVI, MOV, WMV, FLV, WEBM, GIF |
| MKV | MP4, AVI, MOV, WMV, FLV, WEBM |
| AVI | MP4, MKV, MOV, WMV, FLV, WEBM |
| MOV | MP4, MKV, AVI, WMV, FLV, WEBM |

### 音频格式（需 FFmpeg）

| 源格式 | 目标格式 |
|--------|----------|
| MP3 | WAV, OGG, FLAC, AAC, M4A |
| WAV | MP3, OGG, FLAC, AAC, M4A |
| OGG | MP3, WAV, FLAC, AAC, M4A |
| FLAC | MP3, WAV, OGG, AAC, M4A |

### 文本文档（纯 Python 实现）

| 源格式 | 目标格式 |
|--------|----------|
| TXT | HTML, MD, JSON, CSV, XML |
| MD | HTML, TXT, JSON, CSV, XML |
| HTML | TXT, MD, JSON, CSV |
| JSON | CSV, TXT, MD, XML, HTML |
| CSV | JSON, TXT |
| XML | JSON, TXT, MD |
| YAML | JSON, TXT, CSV |

### PDF 处理

| 操作 | 说明 |
|------|------|
| PDF → TXT | 提取文字内容 |
| PDF → MD | 提取文字并格式化 |
| PDF → HTML | 提取文字并生成网页 |

## 五、使用方法

### 命令行

```bash
# 安装依赖
pip install Pillow pypdf

# 转换图片
python run_fconv.py convert input.jpg output.png

# 查看支持的格式
python run_fconv.py formats

# 检测文件格式
python run_fconv.py detect input.jpg

# 查看版本
python run_fconv.py version
```

### Web 界面

```bash
# 启动本地服务
python -m http.server 8000 --directory src/web

# 访问 http://localhost:8000
```
