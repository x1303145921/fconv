## 二、本次修复与新增内容

### 2.1 核心 Bug 修复

**问题**：路由注册逻辑将 PDF 转换器的 `target_formats`（含 `html`）误注册为 `source_formats`，导致 `html→txt` 被错误路由到 PDF 转换器，触发 `invalid pdf header` 错误。

**修复**：将 `_register_builtin()` 中的注册循环从 `source_formats + target_formats` 改为仅 `source_formats`。

```python
# 修复前（错误）
for fmt in instance.source_formats + instance.target_formats:
    ...

# 修复后（正确）
for fmt in instance.source_formats:
    ...
```

**影响**：修复后 `html→txt`、`txt→html`、`md→html` 等文本转换路由正常。

## 五、UI 设计说明

### 5.1 Build 极简风格特征

- **大量留白**：容器最大宽度 640px，上下 padding 80px/120px
- **微妙字重对比**：标题用 700，正文用 400，辅助文字用 500
- **单一强调色**：`#111111` 黑色作为主色，`#16a34a` 绿色用于成功状态
- **边框而非阴影**：所有卡片使用 `1px solid #e5e5e5` 边框
- **圆角克制**：统一 4px，不滥用圆角

### 5.2 三步操作流程

```
Step 1: 上传文件
  └─ 拖放区域 / 点击选择
  └─ 显示文件卡片（扩展名标签 + 文件名 + 文件大小）

Step 2: 选择格式
  └─ 自动推荐目标格式
  └─ 支持标签快速切换
  └─ 支持质量参数调节（JPEG/WEBP）

Step 3: 转换 → 下载
  └─ 进度条动画
  └─ 成功/失败状态反馈
  └─ 一键下载按钮
```

### 5.3 批量转换区

- 独立上传区，支持多文件拖放
- 文件列表展示（扩展名标签 + 文件名 + 大小）
- 转换状态实时更新
- 完成后 ZIP 打包下载

## 六、运行方式

### 6.1 命令行

```bash
# 转换单个文件
fconv convert input.png output.jpg

# 批量转换
fconv batch *.png --format webp -o output/

# 检测文件类型
fconv detect image.jpg

# 查看所有支持格式
fconv formats

# 查看版本
fconv version
```

### 6.2 Web 界面

```bash
# 安装依赖
pip install -e ".[web]"

# 启动服务
python -m src.web.server

# 打开浏览器
open http://127.0.0.1:5000
```

### 6.3 运行测试

```bash
# 单元测试
python -m pytest tests/ -v

# 性能基准测试
python benchmarks/benchmark.py
```
