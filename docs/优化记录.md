## 二、优化改动记录（12 项）

### C01 — 顶部 Logo 区重构
- **改动**：从纯文本 `h1` 改为 Logo 图标 + 品牌名组合
- **依据**：CloudConvert 的 logo 设计，建立品牌识别度
- **来源**：素材 #1
- **效果**：首屏视觉更有品牌感，不再是"工具名 + 一句话"的骨架

### C02 — 步骤指示器新增
- **改动**：在上传区上方增加「1. 上传 → 2. 选择格式 → 3. 开始转换」三步指示
- **依据**：提升任务导向体验，让用户知道当前在哪一步
- **来源**：素材 #5
- **效果**：降低用户认知负担，清晰传达操作流程

### C03 — 上传区域视觉升级
- **改动**：边框颜色加深（从 #e0e0e0 到 #e2e8f0），hover/dragover 时有背景色填充（accent-light）+ 阴影，图标尺寸增大到 56px
- **依据**：交互设计最佳实践 — 明确的悬停反馈能显著提升可用性
- **来源**：素材 #7
- **效果**：上传区域更有"可点击感"，用户体验更流畅

### C04 — 文件卡片替换原有信息展示
- **改动**：从简单的文字行改为带颜色图标的卡片，含文件名/大小/扩展名/删除按钮
- **依据**：现代文件管理器的交互模式（如 Google Drive 拖拽上传后的文件卡片）
- **来源**：素材 #1
- **效果**：已上传文件状态一目了然，且可方便删除重选

### C05 — 格式选择器增强
- **改动**：
  - 下拉菜单改为动态生成（从 FORMAT_DEFS 读取），分组更清晰
  - 新增「推荐格式」快捷标签区，一键选择常用格式
  - 上传文件后自动推荐推荐格式
- **依据**：减少用户操作路径 — 直接推荐而非让用户自己找
- **来源**：素材 #3、#6
- **效果**：新用户无需思考，老用户可以快速切换

### C06 — 质量调节器智能显示
- **改动**：仅当选择 jpg/jpeg/webp 时显示质量滑块，其他格式自动隐藏
- **依据**：无损格式（PNG、GIF、WAV、FLAC）不需要质量参数
- **来源**：素材 #2（竞品分析发现）
- **效果**：减少干扰，界面更干净

### C07 — 支持格式展示区域重构
- **改动**：从 10 个简单 tag 改为按类别分组（图片/视频/音频/文档/PDF），每类一个卡片，显示数量徽章
- **依据**：信息架构原则 — 分类展示比扁平列表更易扫描
- **来源**：素材 #1、#6
- **效果**：33 种格式不再是一堆 tag 堆砌，而是结构化呈现

### C08 — "为什么选择 fconv" 价值主张区新增
- **改动**：新增 4 张功能卡片（隐私安全 / 快速转换 / 格式齐全 / 免费开源），每张有 SVG 图标
- **依据**：落地页的核心要素 — 明确的价值主张能显著提升转化率
- **来源**：素材 #4、#5
- **效果**：从"工具页"升级为"产品介绍页"，利于 GitHub 展示

### C09 — 全局设计系统完善
- **改动**：引入完整 CSS 变量体系（设计令牌），统一 shadow/radius/spacing
- **依据**：设计系统方法论 — 一致性提升专业感
- **来源**：素材 #5
- **效果**：后续维护更容易，视觉一致性更强

### C10 — 响应式布局优化
- **改动**：移动端断点从 600px 调整到 640px，步骤指示器在移动端隐藏文字仅保留数字
- **依据**：现代移动设备宽度普遍在 375px+，需更好地适配
- **来源**：素材 #4
- **效果**：手机端体验更完整

### C11 — Footer 完善
- **改动**：新增导航链接（GitHub/使用文档/常见问题），增加版权信息
- **依据**：专业开源项目的标准 footer
- **来源**：素材 #4
- **效果**：更有项目完整性

### C12 — JS 逻辑重构
- **改动**：将硬编码格式数据提取为 FORMAT_DEFS 配置对象，所有 UI 动态生成
- **依据**：代码可维护性 — 新增格式只需改一处
- **来源**：素材 #3（GitHub 开源项目模式）
- **效果**：后续扩展更方便，减少重复代码

## 五、后续可扩展方向

1. **后端对接**：将模拟转换替换为真实 API 调用（Python Flask/FastAPI 后端）
2. **批量转换**：支持多文件同时上传和转换
3. **历史记录**：用 localStorage 保存最近转换记录
4. **深色模式**：添加 prefers-color-scheme 媒体查询切换
5. **PWA 支持**：添加 manifest.json 和 service worker，支持离线使用
6. **i18n 国际化**：支持英文/中文切换
