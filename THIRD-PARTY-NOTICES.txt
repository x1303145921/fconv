fconv · 第三方组件与许可声明
========================================================================

本项目自身以 MIT 许可证发布（见 LICENSE）。
下面列出运行期涉及的第三方组件、用途与许可。若某组件未随本项目分发，
已明确标注「不分发」，你需要自行安装并遵守其许可。

------------------------------------------------------------------------
一、默认依赖（随 README 安装即包含）
------------------------------------------------------------------------

1. Pillow
   用途：图片格式读写与转换（PNG / JPG / GIF / BMP / TIFF / WEBP / ICO）
   许可证：MIT-CMU（HPND 风格）
   主页：https://python-pillow.org/
   说明：随 requirements.txt 安装，可自由用于商业项目。

2. pypdf
   用途：PDF 文字提取、PDF 转 HTML
   许可证：BSD-3-Clause
   主页：https://pypdf.readthedocs.io/

3. Flask
   用途：本地 Web 服务
   许可证：BSD-3-Clause
   主页：https://flask.palletsprojects.com/

------------------------------------------------------------------------
二、可选依赖（不装也能跑，用到相应格式时才需要）
------------------------------------------------------------------------

4. PyYAML
   用途：YAML 参与互转（yaml ↔ json / csv / xml / ...）
   许可证：MIT
   主页：https://pyyaml.org/
   安装：pip install PyYAML

5. PyMuPDF（fitz）
   用途：PDF 页面渲染为图片（PDF → PNG / JPG）
   许可证：AGPL-3.0（另有商业许可）
   主页：https://pymupdf.readthedocs.io/
   安装：pip install pymupdf
   ⚠️ 重要：AGPL-3.0 是强著佐权许可。本项目**不分发** PyMuPDF，
   也不会自动安装它。若你在对外提供的服务里使用 PDF → 图片功能，
   请自行确认合规方式（购买商业许可，或按 AGPL 开源你的服务）。

------------------------------------------------------------------------
三、外部程序（本项目不分发）
------------------------------------------------------------------------

6. FFmpeg
   用途：视频 / 音频格式转换（mp4 / mkv / avi / mov / wmv / flv / webm / gif、
        mp3 / wav / ogg / flac / aac / m4a）
   许可证：LGPL-2.1+ 或 GPL-2.0+（取决于编译时启用的组件）
   主页：https://ffmpeg.org/
   说明：本项目只通过命令行调用用户自备的 FFmpeg，不打包、不修改其源码。
   若你的 FFmpeg 是 GPL 构建（含 libx264 等 GPL 组件），对外分发含该构建的
   整包时需遵守 GPL 的相应义务。

   处理方式：由 scripts/make-icons.py 自动裁圆、换色、描摹为矢量轮廓后重新渲染，
   生成的图形为本项目原创产出。
